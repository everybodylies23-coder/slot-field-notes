# スロット設定判別・実戦記録

Antigravity作成の総合メニューと機種ポータル、Codex作成の実戦ノートをGitHub Pagesのmain / (root)から配信します。

- index.html：総合メニュー（公開用コピーのノートリンクを既存URLへ調整）
- 海門決戦_設定判別ポータル.html／ジャグラー_設定判別ポータル.html：参照用ポータル
- kabaneri.html／juggler.html：既存の実戦ノート。URL・保存キーを維持
- images/：カバネリポータルが参照する画像

## 追加・更新

元の設定判別フォルダーのHTMLと公開フォルダーは別ファイルです。更新時は差分を確認してから公開用コピーへ反映してください。新機種はHTMLと必要素材を追加し、index.htmlにカードとリンクを追加します。machines.jsは旧メニュー用の一覧で、現在の総合メニューは参照しません。

## 保存と確認範囲

実戦記録はlocalStorageで機種別保存。サーバーへの記録送信や端末間自動同期はなく、ポータルと実戦ノートのデータも自動連携しません。同じ端末・同じブラウザで利用し、JSONを書き出してバックアップしてください。公開リポジトリへ実戦JSON・会話・個人データを追加しないでください。
画像とGoogle Fonts等の取得には通信を使います。ホーム画面への追加だけでは完全オフライン起動を保証しません。
ポータルの追加は機種解析数値の検証完了を意味しません。原本・出典と照合してください。
